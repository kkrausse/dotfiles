* dotfiles

Shared configuration for Zsh, Git, tmux, Ghostty, Vim, Doom Emacs, and Clojure
tools.

** Configuration model

Files in this repository are shared configuration fragments. Each machine has
real local configuration files under =~= which import the shared fragments and
then add machine-specific settings. Do not symlink the live configuration files
to this repository.

This separation keeps paths, identities, credentials, work configuration, and
temporary experiments out of the shared Git worktree. It also means editing a
local override does not dirty this repository.

The copy-once entry points are in =bootstrap/=. Their repository paths are
examples; edit them if the checkout lives somewhere else on a machine.

** Set up a machine

Clone the repository, then copy—not symlink—the entry points. These commands
are for a new machine with no existing files. =cp= follows symlinks, so never
copy a bootstrap file over one of the old links: first move or unlink the link,
then copy the entry point. Never overwrite an existing real local file; merge
its machine-specific contents into the bootstrap file instead.

#+begin_src sh
DOTFILES="$HOME/Documents/repos/kkrausse/dotfiles"

cp "$DOTFILES/bootstrap/zshrc" "$HOME/.zshrc"
cp "$DOTFILES/bootstrap/gitconfig" "$HOME/.gitconfig"
cp "$DOTFILES/bootstrap/tmux.conf" "$HOME/.tmux.conf"
cp "$DOTFILES/bootstrap/vimrc" "$HOME/.vimrc"

mkdir -p "$HOME/.config/ghostty"
cp "$DOTFILES/bootstrap/ghostty_config" "$HOME/.config/ghostty/config"

mkdir -p "$HOME/.doom.d"
cp "$DOTFILES/bootstrap/doom.d/"*.el "$HOME/.doom.d/"
#+end_src

Review every copied file before starting the applications. In particular:

- Set the correct name and email in =~/.gitconfig=.
- Set the checkout path in the import statements.
- Put private and host-specific shell configuration after the shared Zsh
  source line.
- Put host-specific Emacs paths in =~/.doom.d/machine-specific.el=.

The local files load shared settings first, so settings placed after an import
normally act as machine-local overrides.

For a machine using this repository's old symlink layout, inspect and run
=bootstrap/migrate-symlinks.sh=. It refuses to overwrite real files and keeps
each replaced link with a =.pre-import-symlink= suffix.

*** Zsh

=~/.zshrc= sources the repository's =zshrc=. Keep credentials, work aliases,
and host-specific environment variables in the local file.

The shared history search bindings need =fzf= and:

#+begin_src sh
git clone https://github.com/joshskidmore/zsh-fzf-history-search.git \
  "$HOME/.zsh/plugins/zsh-fzf-history-search"
#+end_src

*** Git

=~/.gitconfig= owns identity, signing, credentials, and local overrides. Its
=[include]= section imports the repository's =gitconfig=.

*** tmux, Ghostty, and Vim

Their real local files use each application's native import command:

- tmux: =source-file /path/to/dotfiles/tmux.conf=
- Ghostty: =config-file=/path/to/dotfiles/ghostty_config=
- Vim: =source /path/to/dotfiles/vimrc=

*** Doom Emacs

=~/.doom.d= is a real directory. Its small =init.el=, =packages.el=, and
=config.el= wrappers load their shared counterparts from =doom.d/=. The local
=dotfiles.el= stores the checkout path in one place. =machine-specific.el= and
the Custom-generated =custom.el= remain local.

Run =doom sync= after first setup and whenever shared =init.el= or =packages.el=
changes.

The shared literate configuration is =doom.d/orgconfig.org=. Generated
=orgconfig.el= should not be committed.

** Clojure tools

The repository also contains shared clj-kondo and clojure-lsp configuration and
a Clojure =user.clj=. These tools do not all provide an equivalent native include
mechanism. Prefer a real local config and copy the shared baseline when an
import is unavailable; do not symlink an entire local configuration directory.

** Useful dependencies

On macOS:

#+begin_src sh
brew install fzf ripgrep cmake libvterm clojure/tools/clojure
brew tap d12frosted/emacs-plus
brew install emacs-plus@30 --with-ctags --with-xwidgets
#+end_src

For Vim vinegar:

#+begin_src sh
mkdir -p "$HOME/.vim/pack/tpope/start/vim-vinegar"
git clone https://github.com/tpope/vim-vinegar.git \
  "$HOME/.vim/pack/tpope/start/vim-vinegar"
#+end_src

Worknotes live separately at https://github.com/kkrausse/worknotes.
